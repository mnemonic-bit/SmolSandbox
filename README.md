
# Sandbox For Coding Agents

This small repo uses SmolVM as the micro VM to sandbox Codex. Though it currently supports only a single harness, generally the techniques used here apply to any other harness as well.


## Pre-requisites

To install SmolVM, run

```
curl -sSL https://smolmachines.com/install.sh | bash
```

You can check which version you've just installed by calling

```
smolvm --version
```
